# python-opentelemetry-semantic-conventions

## Build requirements

- The package needs opentelemetry-api at the exact version that the semantic-conventions release pins, which for 0.66b1 is 1.45.1. Keep the requirement at that version so the two packages stay in step.
  Checked against 0.66b1 on openSUSE_Tumbleweed, x86_64.
