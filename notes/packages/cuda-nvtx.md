## Build requirements
- No BuildRequires. The package repackages the upstream prebuilt archive for the build architecture (Source0 is its .tar.xz, kept in the package directory), so no compiler or build library is needed.
- ExclusiveArch limits the package to x86_64, the architecture of that upstream archive. (x86_64 only)
