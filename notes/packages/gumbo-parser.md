# gumbo-parser notes

## Build requirements
- The runtime subpackage is named after the library's soversion. Upstream builds the library at version 4.0.1, so the runtime package is libgumbo4 (soversion 4).
  Checked against 0.14.1 on openSUSE_Factory, x86_64 (from pre-build source review, medium confidence; the build succeeded).
