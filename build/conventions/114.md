114. **C/C++ system-library shims: after one fix, check every consumer of that library in the same turn.** A patch that makes a bundled library use the distro copy (a shim header such as `shims/yyjson/yyjson.hpp`, a `duckdb_apache` namespace alias, a `duckdb_zstd` redirect, a `use-system-*` patch) changes a header name, a namespace or a link target for the whole tree, not only for the file that failed. Upstream then reaches the same library from other places, and each place fails on its own build round.
   - When a build fails with `fatal error: <header>.h: No such file`, `namespace ... not allowed here`, `is not a member of <ns>`, or an undefined reference to a library symbol, and a shim or redirect patch provides that library: fix the failing site, then grep the whole source tree (excluding the bundled `third_party/` copy itself) for every other use of the same header, namespace or library name, in `#include`, `using`, `namespace` alias, and CMake `include_directories`, `target_include_directories`, `add_subdirectory`, `FetchContent` and `find_package` lines.
   - Fix every site that grep finds in the same turn, including CMake files of optional extensions (for example an extension's `CMakeLists.txt` that adds the bundled include path unconditionally). Do not rebuild after the first fix and wait for the next error.
   - A shim that copies an upstream header must not include a header the new upstream release removed (grep the new tree for the included name before copying).
   - A namespace that upstream forward-declares may not be made an alias by a shim. Rename the library's namespace with a define in the flags (`-D<ns>=<name>`) instead, and grep for every other use of that namespace.
   - The patch that carries these changes is one patch per library (convention 14 for quilt and the `PATCH-*` tag format). Update its header in the same turn, not only the file that failed.
