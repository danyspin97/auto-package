115. **A build system switch sets every option explicitly and adds the BuildRequires the new build needs.** Read this when `%configure` or `%make_build` becomes `%meson` or `%cmake` (or the reverse), or a BuildRequires change moves the package to another build system.
   - Read the new tarball first: `meson_options.txt` or `meson.buildoptions` for meson, `CMakeLists.txt` options for CMake. Upstream's NEWS usually says the old system went. The switch is allowed only with that evidence (no `configure.ac` in the tarball, or NEWS says the Autotools build was removed); name it in the reasoning, or the edit is refused.
   - The `.changes` bullet is written by the tool: "Switch to the <system> build system: upstream removed <old>". Do not write a second bullet for the same change.
   - Every doc and feature option the old build set is set explicitly on the new one: `-Dx=enabled` or `-Dx=disabled`, never `auto`, so the result does not depend on what the build host has. An option the old build did not have is left out, and an option upstream removed is dropped (NEWS names it).
   - The BuildRequires the new build needs for each option it enables are added. Meson man pages need `xsltproc` (the openSUSE package `libxslt-tools`) and `docbook-xsl-stylesheets`; without them the man pages are missing and `%files` fails. Check the package names with the build.
   - An old BuildRequires (`xmlto`, `autoconf`, `libtool`) is removed only when the build proves it unused. Keep it otherwise.
   - Digest, dbus-1 1.14.10 to 1.16.2 (Autotools removed in 1.16, NEWS): `%configure` became `%meson`, `%meson_build`, `%meson_test`, `%meson_install`; `BuildRequires: meson` added. `doxygen_docs=disabled`, `inotify`, `libaudit`, `systemd`, `selinux` and `x11_autolaunch` were set to `enabled` or `disabled` as the old flags said. `--with-console-auth-dir` was dropped (the feature is gone). `xml_docs` was left on `auto` while `%files` still listed the man pages, so the fix is `-Dxml_docs=enabled` with the xsltproc and docbook BuildRequires. The build is what settles it.
