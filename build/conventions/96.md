96. **Python spec macro forms: the current ones, and the forms that get submissions declined.**
   - A Python spec has `BuildRequires: python-rpm-macros`.
   - `%python_subpackages` goes alone on its own line at the end of the preamble.
     Every `Requires`, `Recommends`, `Suggests`, `Provides`, `Conflicts` and
     `Obsoletes` line stays above it (convention 65).
   - Never redefine `%python_module`. A `%define python_module python-%1` that drops
     `%{**}` breaks every flavor. Never put `%python_module` in `Requires:`.
   - Do not use `python-rpm-generators` or `%python_enable_dependency_generator` in a
     Factory package.
   - Use `%{$python_...}` (with `$`) inside `%python_expand`, and `%python_bin_suffix`
     for executables and build directories, not `%python_version` (convention 80, 53).
     `%python_prefix` is for per-flavor build directories.
   - Flavor conditionals compare the flavor name:
       %if "%{python_flavor}" == "python311"
       ...
       %endif
     The primary python3 flavor is `%if "%{python_flavor}" == "python3" || "%{python_provides}" == "python3"`.
     For a version check use `%python_version_nodots`.
   - `%ifpython3` is deprecated: write the primary-python3 check above instead.
     `%ifpython2` and `%ifpython3` are only for subpackage sections. Never nest them,
     and never use them in `%prep`, `%build`, `%install` or `%check`.
   - Shebangs of installed scripts are fixed before `%fdupes`:
       %python3_fix_shebang                 (scripts in %{buildroot}%{_bindir})
       %python3_fix_shebang_path <glob>     (scripts anywhere else)
   - A name that must stay as written is masked with `%define oldpython python`, not
     rewritten by hand. Check Factory's copy of the package before using it.
   - Common documentation goes in one subpackage: `%package -n %{name}-doc`. The `-n`
     form stops the per-flavor autogeneration, so the docs are built and packaged once
     (convention 53, skill doc-subpackage).
   - Leap 15 flavors: keep `%{?sle15_python_module_pythons}`, `%{?single_pythons_311plus}`
     and `%{modern_python}-<name>` where the spec has them. A flavor that Leap 15 cannot
     build is skipped with a define such as `%define skip_python310 1`, not by dropping
     a subpackage (convention 89).
   - Source URL of an sdist: `https://files.pythonhosted.org/packages/source/<first
     letter>/<name>/<name>-%{version}.tar.gz`, with no hash path. A GitHub source takes
     the `#/<name>-%{version}.tar.gz` fragment (convention 77).
