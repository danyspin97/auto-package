103. **NPM / nodejs packages: vendor node_modules with the OBS service. The nodejs macros are legacy: do not add them.** The openSUSE nodejs packaging page is marked obsolete.
   - The OBS build has no network, so `npm install` of a package that has
     `dependencies` fails (`getaddrinfo ENOTFOUND`). Do not run it in `%build`.
   - Current method: a `node_modules` `_service` (manual mode, with the cpio, output and
     source-offset parameters) produces the modules. Source10 is `package-lock.json`.
     Source11 is `node_modules.spec.inc`, included with
     `%include %{_sourcedir}/node_modules.spec.inc`.
   - `%prep` runs `local-npm-registry %{_sourcedir} install --also=dev`. `%build` runs
     `npm run build`.
   - Do not introduce `%nodejs_install`, `nodejs_modulesdir`, or a hand-made copy of
     node_modules into the buildroot. Those are the legacy method.
   - For a Python sdist whose build hook runs npm, use the `npm-vendor-packaging` skill.
