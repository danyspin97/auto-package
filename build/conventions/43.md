43. **`setup.cfg`-based pytest config needs `[tool:pytest]`, not `[pytest]`.**
   pytest only recognizes a bare `[pytest]` section in `pytest.ini`/`tox.ini`;
   inside `setup.cfg` the options must live under `[tool:pytest]` (singular
   "tool") or pytest silently ignores the section. (`pyproject.toml` uses
   `[tool.pytest.ini_options]`, convention 12.) Symptom: `testpaths`/
   `addopts`/`markers` in `setup.cfg`'s `[pytest]` section do nothing —
   pytest collects 0 tests (exit code 5) or ignores a visible `addopts`. Fix
   by renaming the section, not by reaching for `%pytest_arch <path>` first:
     sed -i 's/\[pytest\]/[tool:pytest]/' setup.cfg
   Write `tool:pytest` singular, not `[tools:pytest]` (same silent-ignore bug).
