65. **Runtime dependencies are flavor-neutral: `Requires: python-<name>`, never
   `%{python_module <name>}`.** `%{python_module X}` expands to the name of
   EVERY Python flavor, so `Requires: %{python_module click}` makes the python314
   RPM require `python313-click` as well. It is correct only in `BuildRequires`.
   For runtime lines write the plain name and let `%python_subpackages` rewrite
   it per flavor: `Requires: python-click >= 8.1`, `Requires:
   python-python-dotenv` (a distribution called `python-dotenv` is
   `python-python-dotenv`). A conditional dependency needs parentheses:
   `Requires: (python-backports.strenum if python-base < 3.11)`. Without them
   OBS reads `if` as a package (`nothing provides if`) and every dependent is
   unresolvable; never report `if` or `python313-base` in
   `unresolvable_packages`. Put every `Requires`, `Recommends`, `Suggests`,
   `Provides`, `Conflicts` and `Obsoletes` line ABOVE `%python_subpackages`:
   after it the line belongs to no subpackage or lands in the description. The
   pipeline rewrites the simple forms and moves misplaced lines, but a
   conditional form you write is yours to get right.
