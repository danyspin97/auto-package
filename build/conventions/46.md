46. **Strip a stray shebang from a library file that is meant to ship, don't
   delete the file.** A plain importable module under `%{python_sitelib}`
   can carry a `#!/usr/bin/env python` first line left by upstream. rpmlint
   flags it as `non-executable-script`/`wrong-script-interpreter`, feeding
   convention 25's badness budget — but the file is legitimate library
   content, so remove just the shebang line in `%prep`/`%build`, not
   convention 23/24's "delete the whole file/directory" remedy (that is for
   content that should not ship at all):
     sed -i '1{/^#!/d}' path/to/module.py
   Use a comment like "fix non-executable script". Confirm by Reading the first line of
   the file the rpmlint warning names before patching; don't apply this
   blindly to every `.py` file in the tree. A file that IS meant to be run
   (an installed script with a `__main__` purpose) keeps its shebang and gets
   `chmod 0755` in `%install` instead. Never an rpmlintrc filter for either
   (convention 39).
