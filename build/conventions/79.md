79. **Check ELF files for rpmlint's errors before the first build.** For a wheel,
   or any package that ships `.so` files: `readelf -d <lib>` and read its
   RPATH/RUNPATH lines (no `| grep`: only `readelf` itself is allowed). A
   RUNPATH with a build-tree path or an empty entry (`$ORIGIN:`) is Badness
   10000 per file and aborts the build. Fix it in `%install`:
   `BuildRequires: patchelf` and `find %{buildroot} -name '*.so*' -type f -exec
   patchelf --set-rpath '$ORIGIN' {} +` (for a source build,
   `-DCMAKE_SKIP_INSTALL_RPATH=ON`), and `chmod 0755` every shared library
   (convention 39). A filter is the last resort, under convention 39's rules
   (`addFilter("binary-or-shlib-defines-rpath.*<file stem>")`). A wheel or
   subpackage whose RECORD lists no `.so` is `BuildArch: noarch`, otherwise
   `E: no-binary`. Headers follow convention 24 (own headers to `-devel`,
   vendored ones deleted). Delete `*.a` archives and test libraries.
