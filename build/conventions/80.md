80. **`$python` and `%{$python_*}` exist only inside `%python_expand`.** A bare
   `$python` or `%{$python_sitelib}` in `%build`, `%install` or `%check` is
   empty and fails as `-m: command not found` or a path missing its site
   directory; for a one-off generator step write `python3`. Two forms:
   - one line: `%python_expand rm -rf %{buildroot}%{$python_sitelib}/<pkg>/tests`
   - a braced multi-line body, one shell command per line, no backslash
     continuations:
       %{python_expand #
       export PYTHONPATH=%{buildroot}%{$python_sitearch}
       $python -m pytest -k "not test_net"
       }
   A trailing backslash continuation inside either form breaks the expansion
   (`Unterminated {`, a literal `$python`). `%python_exec` runs one line per
   flavor and does not define `$python`.
