95. **A package whose name carries a version number stays on that series.**
   - `fmt-9`, `boost-1.85`, `wlroots-0_15` and `pipewire0_2` are compat packages: the number in the name is the
     series (`9`, `1.85`, `0.15`, `0.2`) and the package follows only releases of that series, never the newest
     release of the project. `update` skips the package when upstream's newest release is of another series.
   - When the series itself has a newer point release (`wlroots-0_15` 0.15.1 -> 0.15.2), update to that one.
   - A number that does not start the packaged version (`foo-2` packaging 1.4) is part of the name and pins
     nothing. `libfoo2` (no dash, no underscore) is a soname, not a series.
   - Never rename the package or bump it to the next series: a new series is a new package.
