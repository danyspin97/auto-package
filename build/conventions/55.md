55. **Two-pass pytest: xdist-safe tests in parallel, xdist-hostile tests
   serially.** When some tests fail only under `pytest-xdist`'s parallel
   scheduling (a GUI backend test that assumes it owns the display, a
   cwd-sensitive test, a process-ordering dependency), do NOT drop `-n auto`
   for the whole suite. Split them with a `no_xdist` accumulator and run two
   passes:

     no_xdist="test_backend or test_span_selector_animated_artists_callback"
     %{python_expand #
     $python -m pytest --pyargs <pkg>.tests -n auto -k "not (${no_xdist} ${skip_tests})"
     $python -m pytest --pyargs <pkg>.tests -k "(${no_xdist}) and not (${skip_tests:4})"
     }
   (one command per line, no backslash continuations: convention 80)

   The first pass runs the bulk in parallel skipping the no-xdist bucket and
   the deselect list. The second runs ONLY the no-xdist bucket without `-n
   auto`, still minus the deselect list. `${skip_tests:4}` strips the leading
   ` or ` so the second `-k` is valid (same trim as convention 48's
   `test_failok` pattern). Example: `python-matplotlib`.
