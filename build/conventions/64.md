64. **A C/C++ library is never packaged as `python-<lib>`.** A native
   library is a package of its own (`libfoo`, `foo-devel`), reported with the
   `lib` prefix and `-devel` suffix removed (convention 27), and looked up in
   upstream source repositories, not on PyPI: a PyPI project that merely
   shares its name is a different thing. Never report a proprietary vendor
   library as a package to build. CUDA/NVIDIA specifics (`nvidia-<lib>-cuNN`
   wheels, `libcuda`, `libnccl`, ...): skill nvidia-wheels.
