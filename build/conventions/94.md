94. **A carried-forward patch is rebased with quilt; it is removed only when it is proven applied.**
   - A patch that does not apply to the new source is rebased: `cd source && quilt push -f`, port the `.rej`
     hunks, `quilt refresh -p ab --no-timestamps --no-index`, keep its comment header and its `series` line.
     A failing hunk in a test file or a `.result` file is rebased like any other.
   - It is removed (spec line, `%patch` line, file, its `series` line) only when `quilt push` of the unchanged
     patch says `can be reverse-applied`: its change is already in the new source. The pipeline checks this and
     rejects a removal without it. "Does not apply", "test only", "obsolete", "probably upstream" are not proof.
   - The `.changes` bullets for refreshed and removed patches are written by the pipeline, one per patch.
   - Prefer quilt; `patch --dry-run` with a relative path is only a read-only fallback, never used to apply.
