68. **Bundled shared libraries in a prebuilt wheel must not leak into RPM
   dependencies.** RPM turns every `.so` under site-packages into `Provides:` and
   every `NEEDED` entry into `Requires:`. For a wheel that bundles its own
   libraries, add before `%description`:
     %global __provides_exclude_from ^%{python_sitearch}/.*$
   (use `%{python_sitelib}` for a purelib wheel) so `libavcodec.so.62` or
   `libz3.so.4.15` inside the wheel does not shadow the distro's. For the sonames
   a wheel links against only through OPTIONAL plugins (NVSHMEM's MPI, UCX,
   fabric and PMIx transports: `libmpi`, `liboshmem`, `libpmix`, `libucp`,
   `libucs`, `libfabric`, `libmlx5`), add `%global __requires_exclude
   ^lib(mpi|oshmem|pmix|ucp|ucs|fabric|mlx5)\.so.*$`: otherwise installing the
   package drags in OpenMPI and UCX for a feature nobody asked for. A wheel
   repaired by auditwheel (a `<name>.libs/` directory, libraries named
   `libavcodec-f34387fd.so.62.11.100` or `libopenblasp-r0-37b5f859.3.3.so`) is
   worse: the `__provides_exclude_from` above removes the Provides of those
   hashed names, yet the auto-generated Requires still name them, so the RPM
   cannot be installed and every package depending on it is `unresolvable`; the
   pipeline's wheel skeleton already writes the `%global __requires_exclude`
   line for it when it sees such libraries (it matches `lib*-<8 hex digits>.so*`
   with at least one letter in the hash, so a date-stamped `libfoo-20240101.so`
   is left alone): keep that line as it is. rpm honours only ONE
   `__requires_exclude`: a second line silently replaces the first, so fold every
   other pattern into the generated regex with `|`
   (`^(<generated pattern without ^ and $>|lib(mpi|ucp)\.so.*)$`) and never add
   another line. For a soname another package of this project supplies,
   exclude the auto-Requires and write the explicit `Requires: python-<that
   package>`, so the choice between flavors is not left to OBS (`have choice
   for lib<x>.so.N`), and add it to `BuildRequires` too when OBS reports that
   choice. Also delete what the runtime does not need from the buildroot in
   `%install`: vendored `include/` headers (convention 24), `*.a` static
   archives, test libraries, and the stubs of another architecture, and list
   the remaining files in `%files` explicitly. `%{_prefix}/external` and other
   non-FHS directories are not created. A copy of a library that stays bundled
   also gets `Provides: bundled(<name>) = <version>` (convention 91).
   CUDA/NVIDIA specifics (NVSHMEM's plugin sonames, `libnccl.so.2`): skill
   nvidia-wheels.
