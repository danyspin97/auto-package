29. Missing source code: when the build fails because a package has no source
   tarball on PyPI and no repository URL in its metadata, you cannot search the
   web for one in this turn. Do not guess a repository URL. Name the project you
   would expect to host it (the official organization) in your evidence. Prefer
   fixing the spec to build from a repository the checkout itself names
   (convention 26) when you can. When PyPI publishes a wheel, set action to
   `use_upstream_wheel`. Otherwise add a `SourceN:` with the release URL of the
   official organisation you named and list it in a `download_files` `_service`
   with `mode="manual"` (convention 92); the pipeline fetches and verifies it.
   The operator can still override the repository with `--source-url`, checked
   before use.
