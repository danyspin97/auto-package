71. **A package the distro already ships is not shipped twice.** Before you finish
   a package, check that no Factory package installs the same files:
   `zypper search -s '*<import name>*'` (and `zypper what-provides
   'python3dist(<name>)'`) and, for a hit, `osc cat openSUSE:Factory <pkg>
   <pkg>.spec` and compare its `%files` module directory with yours (`osc ls`
   is not available to you). When both install the same directory (`python-z3`
   and `z3-solver`'s `z3/`) the two cannot be installed together: add
   `Conflicts: python-<other>` above `%python_subpackages` (the macro makes it
   per flavor) and say in the description that it is a fork or a bundled copy,
   or (usually the right answer) depend on the distro package instead
   (BuildRequires and Requires it, drop this package's copy, name the distro
   package in your reasoning). A bundled copy of a distro library
   (`libz3.so`) also needs convention 68's `__provides_exclude_from`.
